# GigaVibeMiptCode — локальный ИИ‑ассистент в консоли

Консольный чат‑бот, который общается с большой языковой моделью **полностью локально** через Ollama.  
Не требует интернета, API‑ключей, регистрации и платежей.

##  Возможности:

-  Чат с LLM (модель `gemma3:270m` — лёгкая, работает даже на слабых ПК)
-  Контроль длины контекста (по количеству сообщений и символов)
-  Прикрепление файлов через `@::путь/к/файлу::`
-  Обработка больших файлов по частям (`/file_chunk`)
-  Сброс истории (`/reset`) и выход (`\q`)
-  Прерывание ответа модели по `Ctrl+C`
-  Настройка через `.env` и `config.yaml`

##  Требования

- **Операционная система**: Windows 10/11, Linux или macOS
- **Python**: версия 3.10 или выше
- **RAM**: рекомендуется 4+ ГБ
- **Диск**: около 1 ГБ свободного места (модель + окружение)

##  Установка

### 1. Установите Ollama

Скачайте и установите Ollama с официального сайта:

**[Windows](https://ollama.com/download/windows)** · **[Linux](https://ollama.com/download/linux)** · **[macOS](https://ollama.com/download/mac)** 

Или через команду в терминале в зависимости от вашей ОС

Windows:
```bash
irm https://ollama.com/install.ps1 | iex
```

Linux и MacOS:
```bash
curl -fsSL https://ollama.com/install.sh | sh
```


После установки Ollama автоматически запустится в фоне.

### В случае не запущенного Ollama введите команду:

```bash
ollama serve
```


Если после этой введенной команды появляется

```Error ... «Only one usage of each socket address»```, то всё отлично! Поздравляю, мы запустили Ollama

### 2. Скачайте языковую модель

Откройте терминал (cmd, PowerShell или Git Bash) и выполните:

```bash
ollama pull gemma3:270m
```

### 3. Запустите программу

Перейдите в папку final-project, после чего выполните команду:

```bash
python main.py
```
